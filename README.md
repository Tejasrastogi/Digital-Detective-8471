# Digital Detective (`digital-detective-8471`)

## Overview
Welcome to the **Digital Detective** Diwali Independent Learning Assignment. This repository documents an investigation into computer fundamentals: hardware architectures, operating system operations, terminal workflows, software execution models, data and number representations, version control, and computer networking.

Each mission is completed, documented, and committed independently to track progress systematically.
